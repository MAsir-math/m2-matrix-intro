# 矩陣入門實驗室

馬Sir教室 · 中五 M2 · 第 11 章

課堂互動頁。§11.1 用來讀出矩陣的階與元素、辨認特殊矩陣，並根據相等定義列出方程求未知數。§11.2 用來示範矩陣的加減法、純量乘法、矩陣乘法與矩陣的冪，並對齊練習 11A、練習 11B。§11.3 用來示範 2 階和 3 階行列式、子行列式、餘因式與餘因式展式，並對齊練習 11C。

- 網站：<https://masir-math.github.io/m2-matrix-intro/>

## §11.1 矩陣

- A 讀矩陣（`#read`）：調列數／行數，格內顯示 aij 下標，點行或列可高亮；含引入例子（商店貨價）、概念測試站 11.1（`#check11.1`），以及 2×3 與 3×2 的對照。
- B 辨認特殊矩陣（`#identify`）：鎖定例子，可同時選多個名稱（行矩陣、列矩陣、零矩陣、n 階方矩陣、對角矩陣、單位矩陣）。
- C 矩陣相等（`#equal`）：先比較階，同階再比較對應元素；含對照例子、例 11.1（`#ex11.1`）、課堂練習 11.1（`#qp11.1`）與附加例題 11.1（`#extra11.1`）。

標明「自擬」的練習不是課本題。

## §11.2 矩陣的運算

- 運算示範（`#ops`）：兩個可改階的矩陣，可計算 A＋B、A−B、kA、AB、BA 與 Aⁿ。若運算未定義，會說明原因。並備有同階／不同階加減、AB 與 BA、AB＝0 但因子非零、矩陣的冪等情境。
- 加減法（`#add`）：例、課堂練習與附加例題 11.2。
- 純量乘法（`#scalar`）：例、課堂練習與附加例題 11.3–11.5。
- 矩陣乘法（`#mul`）：例、課堂練習與附加例題 11.6–11.9。
- 矩陣的冪（`#power`）：例、課堂練習 11.10–11.11 與附加例題 11.11 的計算部分；數學歸納法證明留在課堂板書，不做成 App 模式。
- 練習 11A（`#exer11A`）、練習 11B（`#exer11B`）：程度 1 題目，答案在學生動手後才揭曉。

數學式由 [KaTeX](https://katex.org/)（MIT）排版。

## §11.3 行列式

- 行列式示範（`#det`）：2 階或 3 階，可用定義求值；點選元素查看子行列式 Mᵢⱼ 與餘因式 Aᵢⱼ；可沿某一行或某一列做餘因式展式。
- 2 階行列式（`#det2`）：例、課堂練習與附加例題 11.12–11.13。
- 3 階行列式（`#det3`）：概念測試站 11.2（`#check11.2`）。
- 子行列式和餘因式（`#minor`）：例、課堂練習與附加例題 11.14。
- 餘因式展式（`#expand`）：例、課堂練習與附加例題 11.15–11.16。
- 練習 11C（`#exer11C`）：程度 1 與程度 2 的計算題；證明題（第 5、6、27(a)、28 題）留在課堂板書，不做成 App 模式。
- 階段評估 11.3（`#assess11.3`）。

本課程只學 2 階和 3 階行列式。這裏的「| |」不是絕對值。
