# 矩陣入門實驗室

馬Sir教室 · 中五 M2 · §11.1 矩陣

課堂互動頁，用來讀出矩陣的階與元素、辨認特殊矩陣，並根據相等定義列出方程求未知數。本頁只涵蓋定義、特殊矩陣與相等性。

## 使用

- 網站：<https://masir-math.github.io/m2-matrix-intro/>
- 亦可把本資料夾放在本機伺服器開啟（需能連 jsDelivr 以載入 KaTeX 與字型）。
- Google Sites：插入 → 嵌入 → 以網址嵌入上述網址。
- 可用網址後綴跳到指定模式或題目，例如 `#read`、`#identify`、`#equal`、`#check11.1`、`#ex11.1`、`#qp11.1`、`#extra11.1`。預設含概念測試站 11.1、例 11.1、課堂練習 11.1 與附加例題 11.1，一開始就可以選。

本頁不收集學生資料，沒有帳號，也不會把姓名寫進瀏覽器儲存。

## 模式

- A 讀矩陣（`#read`）：調列數／行數，格內顯示 aij 下標，點行或列可高亮；含引入例子（商店貨價）、概念測試站 11.1（`#check11.1`），以及 2×3 與 3×2 的對照。
- B 辨認特殊矩陣（`#identify`）：鎖定例子，可同時選多個名稱（行矩陣、列矩陣、零矩陣、n 階方矩陣、對角矩陣、單位矩陣）。
- C 矩陣相等（`#equal`）：先比較階，同階再比較對應元素；含對照例子、例 11.1（`#ex11.1`）、課堂練習 11.1（`#qp11.1`）與附加例題 11.1（`#extra11.1`）。

標明「自擬」的練習不是課本題。

數學式由 [KaTeX](https://katex.org/)（MIT）排版。
